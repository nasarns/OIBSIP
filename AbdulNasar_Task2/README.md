BMI Calculator (TASK 1):

  Project Description:
  --------------------
    =>The BMI Calculator is a simple Python command-line application developed as part of the OIBSIP Python Programming Internship.

    =>The program takes a user’s weight and height. 

    =>Calculates the Body Mass Index (BMI) and displays the corresponding BMI category: Underweight, Normal, Overweight or Obese.

  Objective:
  -------------------
    The main objective of this project is to create a simple, user-friendly Python program that can accept user weight and height, calculate BMI, classify the result, display it clearly and  handle invalid input.

    * Accept weight and height from the user
    * Calculate BMI
    * Classify the BMI result
    * Display the result clearly
    * Handle invalid user input

  Features:
  ----------------------
    * Weight input in kilograms
    * Height input in meters
    * BMI calculation
    * BMI displayed up to two decimal places
    * Four BMI categories:
      * Underweight
      * Normal
      * Overweight
      * Obese
    * Validation for invalid numeric input
    * Validation for zero and negative values
    * Simple command-line interface

  BMI Formula:
  --------------------------
    =>The BMI is calculated using the following formula:

    BMI = Weight / (Height × Height)

    Where:

      =>Weight is measured in kilograms
      =>Height is measured in meters

    BMI Categories:
    ----------------------------	
    BMI Range	   Category
    -----------   ----------------
    Below 18.5	 - Underweight
    18.5 - 24.9	 - Normal
    25 - 29.9	 - Overweight
    30 and above - Obese


    Technologies Used:
    --------------------------
        * Python 3
        * Python built-in input() function
        * Conditional statements
        * Exception handling
